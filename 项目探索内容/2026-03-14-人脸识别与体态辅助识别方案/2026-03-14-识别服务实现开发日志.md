# 2026-03-14 识别服务实现开发日志

## 1. 当前成果（已落地）
- 已实现本地 Docker 化多人识别服务，支持近距离（约 3-5 米）最多 5 人同屏识别。
- 已实现前端 Web 摄像头采集 + 实时识别展示 + 目标选择命名。
- 已实现“未知人员自动入库”，可后续补充 `名称` 和 `关系`。
- 已实现识别结果携带 `名称/关系`，不再只显示 `person_x`。
- 已接入模型缓存目录，避免容器重启后反复下载模型。
- 已修复“同帧两人都显示为同一已命名人员”的核心逻辑问题。

## 2. 技术方案（最终采用）

### 2.1 整体架构
- 后端：FastAPI（`app/main.py`）
- 前端：纯 HTML/JS（`web/index.html`）
- 运行：Docker Compose（`docker-compose.yml`）
- 数据存储：SQLite（`data/identity.db`）

### 2.2 识别链路
1. YOLOv8 人体检测 + ByteTrack 跟踪，产出 `track_id`。
2. InsightFace 提取人脸特征（主特征）。
3. ResNet18 提取人体特征（辅助特征）。
4. 多模态决策顺序：
   - `face` 命中（阈值通过）优先
   - 否则使用短时遮挡保持 `hold`
   - 否则尝试 `body` 命中
   - 否则回退到 track 缓存
   - 仍无结果则创建新 `unknown person`

### 2.3 关键阈值与参数（Compose 环境变量）
- `MAX_PEOPLE=5`
- `FACE_SIM_THRESHOLD=0.62`
- `BODY_SIM_THRESHOLD=0.72`
- `OCCLUSION_HOLD_MS=1500`
- `TRACK_TTL_MS=2200`
- `ALLOW_FALLBACK=0`（默认关闭 fallback，强制 InsightFace）

## 3. 实现细节

### 3.1 数据模型
- `persons`：人员主表
  - `person_id`（主键）
  - `display_name`（可空）
  - `relation_desc`（可空）
  - `created_at`, `updated_at`
- `templates`：特征模板表
  - `person_id`
  - `modality`（`face` / `body`）
  - `vector_json`, `sample_count`, `updated_at`

说明：
- 旧库自动迁移支持 `relation_desc` 字段补齐。
- `display_name` 已兼容可空（未知人员）。

### 3.2 API
- `POST /api/frame`：上传当前帧，返回多人识别结果。
- `POST /api/name`：给指定 `track_id` 绑定/更新 `name` 与 `relation`。
- `GET /api/people`：返回当前人员列表（含未知人员）。
- `GET /healthz`：服务健康、模式与统计信息。

### 3.3 前端交互
- 摄像头实时采样上传，返回结果后渲染框与标签。
- 支持点击“选中命名”，将 `track_id` 与输入的名称/关系提交。
- 人员列表显示：`person_id`、名称、关系、状态（已命名/待完善）。

### 3.4 本次关键修复（多人同框串人）
问题现象：
- 先注册一个人后，第二个人进入画面，两个目标都显示第一个人的信息。

根因与修复：
1. 人脸到人体轨迹绑定策略优化  
   - 从“最大包含框”改为“最小包含框”，减少遮挡场景误归属。
2. 同帧身份唯一性约束  
   - 增加 `assigned_person_ids` 去重：同一帧内一个 `person_id` 最多绑定一个可见 `track`。

效果：
- 明显降低双人面对面/局部遮挡时“同帧共用同一 identity”的概率。

## 4. Docker 与模型缓存

### 4.1 挂载策略
- `./data:/app/data`
- `./model-cache/insightface:/root/.insightface`
- `./model-cache/torch:/root/.cache/torch`
- `./model-cache/ultralytics:/tmp/Ultralytics`

### 4.2 结果
- 首次冷启动下载后，后续重启直接走本地缓存，不再重复下载。
- `.gitignore` 已加入 `model-cache/`，避免缓存文件入库。

### 4.3 依赖稳定性
- 已在 `requirements.txt` 固定 `lap>=0.5.12,<1`，避免 Ultralytics 运行时自动安装导致抖动。
