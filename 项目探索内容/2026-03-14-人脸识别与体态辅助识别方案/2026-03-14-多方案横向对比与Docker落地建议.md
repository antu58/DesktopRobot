# 2026-03-14 多方案横向对比与 Docker 落地建议

更新时间：2026-03-14

## 1. 背景

你要的目标是：

1. Web 页面采集摄像头。
2. 识别到的人可以被命名（例如把 `person_1` 绑定为“张三”）。
3. 后续识别时直接返回名字。
4. 项目运行在 Docker 中。

## 2. 横向对比（可直接选型）

| 方案 | 架构 | 准确性 | 开发复杂度 | Docker 复杂度 | 首版交付速度 | 适合场景 |
|---|---|---|---|---|---|---|
| A. 浏览器提特征 + 轻后端检索 | 前端做人脸 embedding，后端只做向量匹配+命名 | 中 | 低 | 低 | 最快（当日） | 先跑通业务闭环/PoC |
| B. 后端 InsightFace 主链路 | 后端 `SCRFD + ArcFace`，前端只采集视频帧 | 中高~高 | 中 | 中 | 1~2 天 | 工程化上线前主路径 |
| C. InsightFace + ReID/步态增强 | B + `ByteTrack/BoT-SORT` + ReID（可加 OpenGait） | 高（复杂场景更稳） | 高 | 高 | 3~7 天 | 遮挡/远距/多人复杂场景 |

## 3. 各方案细节

## 3.1 方案 A（最简可运行）

实现：

1. 前端 `getUserMedia()` 采集摄像头。
2. 前端人脸检测与 embedding（浏览器内完成）。
3. 后端（Python）存储模板与名字（SQLite）。
4. 识别接口返回 `person_id + display_name`。

优点：

1. 依赖最少，最容易 Docker 化。
2. 能最快验证“识别 -> 命名 -> 下次带名字返回”的闭环。

风险：

1. 对光照、角度、遮挡鲁棒性一般。
2. 大规模/高并发/高准确要求时需升级到 B 或 C。

## 3.2 方案 B（推荐工程主线）

实现：

1. 后端使用 InsightFace `FaceAnalysis`（检测+识别 embedding 一体）。
2. 前端只上传帧，不承担推理。
3. 后端向量检索 + 阈值判定 + 命名绑定。

优点：

1. 准确性和稳定性更强，服务端可控。
2. 前端更轻，便于统一升级模型。

风险：

1. 镜像体积更大，模型下载与运行时依赖更多。
2. CPU 下性能可用但需要节流（比如 1~2fps 识别）。

## 3.3 方案 C（复杂场景增强）

实现：

1. 以 B 为基础。
2. 新增跟踪器（ByteTrack/BoT-SORT）稳定轨迹 ID。
3. 新增人体 ReID，必要时加步态分支（OpenGait）做辅助融合。

优点：

1. 在侧脸、背脸、短时遮挡时更稳。
2. 多目标跟踪场景下 identity switch 更少。

风险：

1. 研发和运维复杂度明显上升。
2. 需要更系统的数据与阈值标定。

## 4. Docker 落地建议

统一建议使用 `docker compose`，最小服务分层：

1. `web`：前端页面（Nginx 静态托管）。
2. `api`：识别服务（Python）。
3. `db`：PoC 可 SQLite（volume 持久化），进阶可 Postgres + pgvector。

推荐起步：

1. 先用 `A` 跑通功能闭环。
2. 保持接口不变，后端内部可无缝替换为 `B`。
3. 未来增加 `reid-service` 升级到 `C`。

## 5. 结合你的要求的推荐

在“你要先选型 + 需要 Docker + 先做最简单可用”的前提下，推荐优先级：

1. **首选 A**：当天即可交付可用闭环（含命名持久化）。
2. **二阶段 B**：在不改前端交互的情况下提升准确性。
3. **三阶段 C**：复杂遮挡与远距场景再上。

## 6. 外部依据（最新可用实现参考）

1. InsightFace Python 包提供 `FaceAnalysis`，支持检测与人脸识别能力：<https://pypi.org/project/insightface/>
2. ArcFace 是当前工程界最常用的人脸 embedding 基线之一：<https://arxiv.org/abs/1801.07698>
3. ByteTrack 通过关联低分框提升跟踪连续性：<https://arxiv.org/abs/2110.06864>
4. BoT-SORT 融合运动与外观，提升多目标跟踪指标：<https://arxiv.org/abs/2206.14651>
5. FastReID 是常用 ReID 工程工具箱，且仓库提供 Docker 目录：<https://github.com/JDAI-CV/fast-reid>
6. OpenGait 项目近期仍在持续更新（含 2025 年更新记录）：<https://github.com/ShiqiYu/OpenGait>
7. Web 端摄像头采集需安全上下文（HTTPS/localhost）：<https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia>
